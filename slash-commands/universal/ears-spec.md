# /ears-spec

Invokes the `ears-spec-writing` skill with the `SPEC_TEMPLATE.md` template.
Asks for: feature name, context, primary actors, data classes, compliance scope.
Produces `specs/<domain>/<feature>.md`.

Run as: `/ears-spec <feature-name>`
