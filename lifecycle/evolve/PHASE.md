# Phase: Evolve

## Activities

- Major version increments
- New feature rollouts
- Refactors (in `refactor` mode)
- Migrations (in `migration` mode)
- Tech-debt paydown

## This phase runs in parallel with `operate`.

The system is live; you're improving it. Use the lifecycle phases inside this
one for individual evolutions: each big change goes through its own
discovery → design → build → harden → launch micro-cycle.
