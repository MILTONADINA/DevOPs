One variable to install.

Stratum speaks the Anthropic API, so your tools and SDKs don't change. Point them at it once.

01 — INSTALL

Redirect the base URL

Set ANTHROPIC_BASE_URL to your Stratum endpoint and authenticate with your key. Every request now routes through the gateway — no code change.

02 — MEASURE

Count, then cut

Each turn is metered with the provider's exact usage; the re-sent, irrelevant context is identified and pruned behind a published <5% quality gate.

03 — SETTLE

Pay 20% of savings

Your provider bill falls; Stratum invoices a fifth of the measured drop. No savings, no fee — every figure signed and reconcilable.

Infrastructure, not a plugin.

Exact accounting, every provider, adversarially hardened.

A1

Drop-in compatible

Speaks the Anthropic Messages API. Claude Code, the SDKs, and any Anthropic-shaped client work unchanged — a new base URL is the whole integration.

A2

Run anywhere

One endpoint routes by model id to Anthropic, OpenAI, Gemini, OpenRouter, or a local server — request, response, and streaming translated faithfully back to the Anthropic shape.

A3

Exact token accounting

Billing uses the upstream-confirmed input/output counts — never an estimate. Provable, HMAC-signed, dispute-proof.

A4

Context pruning

The KadaneDial engine ranks and removes the redundant re-sent context, gated behind a faithfulness eval so quality never silently degrades.

A5

Security-hardened

Row-level security on every table, an append-only financial ledger, PII redaction, and multiple adversarial audits plus a full penetration test.

A6

Transparent settlement

A CFO dashboard and signed audit trail show exactly what was saved and what was charged — auth, invoice, paid, reconciled, down to the session.
