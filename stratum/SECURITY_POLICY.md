# SECURITY_POLICY.md

This file is kept so that existing links to it still resolve. It is not a
separate policy.

The single security policy for the whole repository, including Stratum
(`stratum/`), is [`../docs/SECURITY.md`](../docs/SECURITY.md). To report a
vulnerability, follow its
[Reporting a vulnerability](../docs/SECURITY.md#reporting-a-vulnerability)
section. Do not open a public issue for a vulnerability.
